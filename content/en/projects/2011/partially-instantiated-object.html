body: >-


Diasec-mounted photographic print, 44 x 140 cm


Partially Instantiated Object is a Diasec photograph of a text written in a computer programming language that formally describes a virtual camera in three-dimensional space. The title Partially Instantiated Object refers to instantiation, which, in computer science, defines the action of creating an object from a model. This description refers to the pinhole camera and the accompanying optical and mathematical theories.   In fact, the pinhole camera serves as a model for the construction of a camera that allows one to define a viewpoint in three-dimensional space—that is, one built on three axes (x, y, z)—rather than two (x, y) as is the case with flat surfaces. But here, the object is only partially instantiated, since the program is rendered on photographic media rather than on a screen. Through this photograph, in which text and image are formally intertwined, Jeff Guess reveals the production process behind the two video projections presented in the central space of the exhibition.

Production : La Criée centre d'art contemporain, Rennes
